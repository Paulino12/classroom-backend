# Classroom Backend

This is the backend for the Classroom application.

## Tech Stack
- Node.js
- TypeScript
- Express
- Drizzle ORM
- Neon (PostgreSQL)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Set up environment variables:
   Create a `.env` file and add your `DATABASE_URL`.

3. Run the development server:
   ```bash
   npm run dev
   ```
